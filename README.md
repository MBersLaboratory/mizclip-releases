# MIZCLIP — releases

Сайт и установщики MIZCLIP — общего буфера обмена и передачи «Рядом» для Mac, Windows, Linux и Android.
Website and installers for MIZCLIP — a shared clipboard and Nearby transfer for Mac, Windows, Linux and Android.

**Скачать / Download:** https://mberslaboratory.github.io/mizclip-releases/

- Здесь только сайт (GitHub Pages) и установщики (GitHub Releases); исходный код приложения хранится в закрытом репозитории.
  This repository holds only the website and the installers; the app source code is private.
- У каждого файла на сайте и в заметках к выпуску указан SHA-256 — сверяйте перед установкой.
  Every file has a SHA-256 checksum on the website and in the release notes — check it before installing.
- Сайт без трекеров, cookies и аналитики. / The website has no trackers, cookies or analytics.
