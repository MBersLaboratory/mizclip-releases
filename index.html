Как установить

У MIZCLIP пока нет подписи Apple и Microsoft, поэтому при первом запуске система предупредит о неизвестном разработчике. Это ожидаемо — ниже написано, как открыть.

macOS
  1. Откройте .dmg и перетащите MIZCLIP в «Программы».
  2. macOS 14 и раньше: в «Программах» правый клик по MIZCLIP → «Открыть» → в окне предупреждения снова «Открыть».
  3. macOS 15 и новее: откройте MIZCLIP → «Готово» в окне «не удалось проверить» → «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть» → пароль Mac → «Открыть».
  4. Если macOS пишет, что приложение «повреждено», выполните в Терминале: xattr -dr com.apple.quarantine /Applications/MIZCLIP.app
  5. Чтобы MIZCLIP вставлял в другие приложения, разрешите «Универсальный доступ», когда macOS попросит.

Дальше MIZCLIP открывается обычным двойным кликом. Новая версия ставится поверх — данные сохраняются.

Windows
  1. Скачайте .exe. Если браузер предупредит о редком файле — «Сохранить» / «Всё равно сохранить».
  2. Запустите файл. SmartScreen покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
  3. MIZCLIP ставится сразу для текущего пользователя, права администратора не нужны. Ярлыки — на рабочем столе и в «Пуске».
Linux
  1. Ubuntu, Debian — пакет .deb, зависимости подтянутся сами: sudo apt install ./MIZCLIP-*-linux-amd64.deb
  2. Fedora и другие — AppImage: chmod +x MIZCLIP-*.AppImage && ./MIZCLIP-*.AppImage
  3. Ubuntu 22.04: для AppImage нужен sudo apt install libfuse2. Ubuntu 24.04 и новее: если AppImage не запускается — поставьте .deb или запустите с ключом --no-sandbox
  4. Нужно хранилище ключей — GNOME Keyring или KWallet. Значок в трее на GNOME в Debian и Fedora — расширение «AppIndicator and KStatusNotifierItem Support».
Android
  1. Скачайте .apk на телефон и откройте его — из уведомления браузера или из «Загрузок».
  2. Android попросит разрешение: «Настройки» → «Разрешить установку из этого источника» → назад → «Установить».
  3. Если Google Play Защита предупредит о неизвестном приложении — «Подробнее» → «Всё равно установить».
  4. Новая версия ставится поверх прежней — данные сохраняются.
iPhone и iPad

Версия для iPhone и iPad пока не выпущена: её можно собрать и поставить на свой телефон только из Xcode. Когда появится в App Store или TestFlight — ссылка будет здесь.

Проверить файл

Сравните SHA-256 скачанного файла с суммой у этого файла на странице — они должны совпасть до последнего знака.

macOS shasum -a 256 MIZCLIP-*.dmg

Linux sha256sum MIZCLIP-*

Windows (PowerShell) Get-FileHash .\MIZCLIP-*.exe

Подпись APK, сертификат SHA-256
